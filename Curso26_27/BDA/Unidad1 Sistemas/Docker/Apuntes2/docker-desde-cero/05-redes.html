Redes: como hablan los contenedores entre si

Una app casi nunca vive sola — necesita hablar con una base de datos, con otro servicio. ¿Como se encuentran dos contenedores distintos?

1. Por defecto, cada contenedor esta aislado

Cuando arrancas un contenedor sin especificar nada, Docker lo conecta a una red "bridge" por defecto. Ahi los contenedores pueden salir a internet, pero no se encuentran entre si por nombre facilmente. Para que dos contenedores tuyos se hablen de forma fiable, la practica real es crear tu propia red.

2. Crea tu propia red — y el nombre del contenedor se convierte en su direccion

bash - Red personalizada, paso a paso 
docker network create mi_red

docker run -d --name servidor_bd --network mi_red mariadb:11.4 \
  -e MARIADB_ROOT_PASSWORD=secreto

docker run -it --name cliente --network mi_red ubuntu bash
# dentro del contenedor cliente:
ping servidor_bd

El ping funciona. Esa es la pieza clave: dentro de una red personalizada, Docker monta un DNS interno automatico — el nombre del contenedor ES su direccion. No necesitas saber ninguna IP. Tu aplicacion puede conectarse literalmente a servidor_bd como si fuera un nombre de dominio real, y Docker resuelve cual es ese contenedor por debajo.

INFO
Por que esto importa de verdad: es el mecanismo que hace posible que, por ejemplo, un servidor web se conecte a db:5432 sin que nadie tenga que ir a buscar y actualizar una IP cada vez que el contenedor de la base de datos se reinicia (las IPs internas pueden cambiar; el nombre, no).

3. Comandos para inspeccionar redes

bash - Ver el estado de las redes 
docker network ls                # que redes existen
docker network inspect mi_red    # que contenedores estan conectados, con que IP

4. Que deberia quedarte claro al cerrar este capitulo

  • Contenedores en redes distintas (o en la red por defecto sin red propia) no se encuentran entre si de forma fiable.
  • Una red personalizada (docker network create) da DNS interno gratis: el nombre del contenedor es su direccion.
  • Este mecanismo es la base de todo lo que viene en el proximo capitulo: Compose crea esta red por ti automaticamente.
