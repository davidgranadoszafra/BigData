Que cubre el curso

De "que es un contenedor" a construir imagenes optimizadas y orquestar varios servicios.

CORE

Los conceptos que lo sostienen todo

Imagen vs contenedor, por que Docker no es una maquina virtual, y los comandos que se usan todos los dias.

BUILD

Construir tus propias imagenes

Dockerfile paso a paso, por que el orden de las instrucciones afecta a la velocidad de build, y multi-stage builds para imagenes mas pequenas.

DATA

Datos y comunicacion entre contenedores

Volumenes para que los datos sobrevivan al contenedor, y redes para que varios contenedores se encuentren por nombre.

COMP

Docker Compose, basico y avanzado

Levantar varios servicios con un solo fichero, y hacerlo robusto de verdad con healthchecks y variables en .env.
